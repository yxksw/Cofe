# 新文章通知功能技术文档

## 1. 功能概述

新文章通知功能是一个基于 RSS 订阅的博客文章更新检测系统，主要功能包括：

- **自动检测**：页面加载后自动获取 RSS 订阅源
- **IndexedDB 存储**：使用浏览器本地 IndexedDB 存储已读取的文章内容
- **差异比较**：比较新旧文章内容，检测更新
- **通知弹窗**：显示新文章和更新文章列表
- **文章内高亮**：在文章页面显示变更内容的差异高亮
- **一键跳转**：点击通知项自动跳转到文章并高亮变更

### 3.2 数据类型定义

```typescript
interface Post {
  title: string;           // 文章标题
  link: string;            // 文章链接
  guid: string;           // 文章唯一标识
  pubDate: number;        // 发布时间戳
```

### 3.3 RSS 数据获取

```typescript
const fetchRSS = async (): Promise<Post[]> => {
  // 添加时间戳防止缓存
  const timestamp = Date.now()
  const response = await fetch(`/atom.xml?t=${timestamp}`, { 
    cache: 'no-store',
    headers: {
      'Cache-Control': 'no-cache, no-store, must-revalidate',
      'Pragma': 'no-cache'
    }
  })
  const text = await response.text()
  const parser = new DOMParser()
  const xml = parser.parseFromString(text, 'text/xml')

  const items = Array.from(xml.querySelectorAll('entry'))

  return items.map((item) => ({
    title: item.querySelector('title')?.textContent || '',
    link: item.querySelector('link')?.getAttribute('href') || '',
    guid: normalizeGuid(rawGuid || link, link),
    pubDate: new Date(pubDateStr).getTime(),
    content: item.querySelector('content')?.textContent || '',
    description: item.querySelector('summary')?.textContent || '',
  }))
}
```

### 3.4 差异计算

```typescript
function computeDiff(oldText: string, newText: string) {
  if (!oldText || !newText) return null

  // 直接对原始文本进行行级 diff
  const diffs = Diff.diffLines(oldText, newText)
  const hasChanges = diffs.some((part) => part.added || part.removed)

  if (!hasChanges) return null

  return diffs
}
```

### 3.5 IndexedDB 操作

```typescript
// 打开数据库
const openDB = (): Promise<IDBDatabase> => {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open(DB_NAME, DB_VERSION)
    request.onerror = () => reject(request.error)
    request.onsuccess = () => resolve(request.result)
    request.onupgradeneeded = (event) => {
      const db = event.target.result
      // 创建对象存储
      if (!db.objectStoreNames.contains(STORE_OLD)) {
        db.createObjectStore(STORE_OLD, { keyPath: 'id' })
      }
    }
  })
}

// 保存文章（先清空再存储）
const savePosts = async (db: IDBDatabase, posts: Post[]) => {
  const transaction = db.transaction([STORE_OLD], 'readwrite')
  const store = transaction.objectStore(STORE_OLD)
  
  // 先清空旧数据
  await store.clear()
  
  // 存储新数据
  posts.forEach((post) => {
    store.put({ ...post, id: generateId(post.guid) })
  })
}
```

## 4. 组件说明

### 4.1 NewPostNotification 组件

主要职责：

1. **初始化检测**：组件挂载时立即检查新文章
2. **定时轮询**：每 5 分钟自动检查一次
3. **通知展示**：显示新文章/更新文章列表
4. **数据存储**：将 diff 数据存储到 sessionStorage 供文章页面使用

核心逻辑：

```typescript
useEffect(() => {
  checkForNewPosts()
  // 定时检查
  intervalRef.current = setInterval(checkForNewPosts, CHECK_INTERVAL)

  return () => clearInterval(intervalRef.current)
}, [checkForNewPosts])
```

### 4.2 PostDiffViewer 组件

主要职责：

1. **读取 diff 数据**：从 sessionStorage 读取当前文章的 diff 数据
2. **显示 diff 面板**：在文章右上角显示变更列表面板
3. **文章中高亮**：点击高亮按钮在文章内容中显示变更
4. **自动高亮**：如果 URL 有 `?diff=1` 参数，自动应用高亮

核心逻辑：

```typescript
useEffect(() => {
  const currentPath = window.location.pathname
  const postKey = `post-diff-${currentPath}`
  const stored = sessionStorage.getItem(postKey)
  
  if (stored) {
    const data: PostDiffData = JSON.parse(stored)
    if (data.diff && data.diff.length > 0) {
      setDiffData(data)
      setIsVisible(true)
      
      // URL 有 diff 参数时自动高亮
      if (hasDiffParam) {
        setTimeout(() => highlightChanges(data.diff), 500)
      }
    }
  }
}, [])
```

## 5. 差异高亮原理

### 5.1 差异定位流程

```
文章内容 DOM
    │
    ▼
┌─────────────────────────────────────┐
│  1. 构建 diff 行 (buildRows)         │
│  2. 提取上下文 (sliceWithContext)    │
│  3. 分块处理 (toHunks)               │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  对于每个 hunk：                      │
│  - 查找锚点元素（上下文）              │
│  - 处理替换（del + add）              │
│  - 处理新增（add）                    │
│  - 处理删除（del）                    │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  生成 HTML 结构：                    │
│  <div class="post-inline-diff-add-line"> 新增内容 </div>
│  <div class="post-inline-diff-del-line"> 删除内容 </div>
│  <span id="post-diff"></span> (锚点)
└─────────────────────────────────────┘
```

## 6. 工作流程

### 6.1 首次访问

```
用户访问博客
    │
    ▼
NewPostNotification 组件挂载
    │
    ▼
获取 RSS 数据 (/atom.xml?t={timestamp})
    │
    ▼
存储到 IndexedDB (STORE_OLD)
    │
    ▼
设置初始时间戳到 localStorage
    │
    ▼
不显示通知（首次访问）
```

### 6.2 后续访问（检测到变更）

```
用户刷新页面
    │
    ▼
获取 RSS 数据（带时间戳防缓存）
    │
    ▼
读取 IndexedDB 中存储的文章
    │
    ▼
逐篇比较内容差异
    │
    ├─ 新文章 ──→ 标记为 "新文章"
    │
    └─ 内容变化 ─→ 计算 diff → 标记为 "更新"
    │
    ▼
更新 IndexedDB 存储
    │
    ▼
存储 diff 数据到 sessionStorage
    │
    ├─ 列表格式：'cofe-diff-debug-state'
    │
    └─ 单文章格式：'post-diff-${pathname}'
    │
    ▼
显示通知弹窗 + 红点提示
```

### 6.3 查看文章变更

```
用户点击通知项（带 ?diff=1#post-diff）
    │
    ▼
跳转到文章页面
    │
    ▼
PostDiffViewer 组件挂载
    │
    ▼
读取 sessionStorage：'post-diff-${pathname}'
    │
    ▼
显示 diff 面板（右上角）
    │
    ▼
检测到 URL 有 diff 参数
    │
    ▼
自动调用 applyInlineDiff
    │
    ▼
在文章内容中高亮显示变更
    │
    ▼
滚动到 #post-diff 锚点位置
```

### 6.4 手动高亮变更

```
用户点击 diff 面板中的"高亮"按钮
    │
    ▼
调用 highlightChanges(diff)
    │
    ▼
查找文章容器 (.markdown-body, .prose, article)
    │
    ▼
调用 applyInlineDiff(container, diff)
    │
    ▼
在文章内容中插入高亮标记
    │
    ▼
显示底部提示"变更已高亮"
```

### 6.5 关闭通知

```
用户点击关闭按钮
    │
    ▼
清除 sessionStorage：
    ├─ 'post-diff-${pathname}'
    ├─ 'cofe-diff-debug-state'
    └─ 'active-post-changes'
    │
    ▼
清除 localStorage：
    └─ 'cofe-notification-state'
    │
    ▼
调用 clearInlineDiff(container)
    │
    ▼
移除 URL 参数 (?diff=1)
    │
    ▼
隐藏 diff 面板
```

## 10. 注意事项

1. **隐私考量**：所有数据存储在用户本地浏览器，不涉及服务器端存储
2. **性能考虑**：差异计算和 DOM 操作可能影响性能，建议对大文章进行优化
3. **缓存策略**：RSS 请求使用 `cache: 'no-store'` 和时间戳确保获取最新数据
4. **存储限制**：sessionStorage 有大小限制（通常 5-10MB），大文章 diff 可能超出限制
5. **清理机制**：关闭通知后会自动清理相关状态，避免持久化污染
6. **兼容性**：依赖 IndexedDB 和 sessionStorage，旧版浏览器可能不支持
