# 新文章通知功能技术文档

## 1. 功能概述

新文章通知是一个基于 RSS 订阅检测的系统，能够自动检测博客文章的新增和更新，并通过多种方式通知用户。

### 1.1 核心功能
- **RSS 订阅检测** - 定时获取博客 RSS 数据（每 5 分钟）
- **文章对比** - 使用 diff 算法比较文章变更
- **本地存储** - 使用 IndexedDB 存储文章历史
- **UI 通知** - 悬浮通知面板展示新文章和更新
- **文章内变更展示** - 悬浮面板显示变更摘要
- **文章内变更高亮** - 在文章正文中高亮显示变更内容
- **红点提示** - 未读新文章时显示红点提醒

### 1.2 技术栈
| 技术 | 用途 |
|------|------|
| IndexedDB | 本地数据存储 |
| diff | 文本差异对比 |
| React Hooks | 状态管理 |
| sessionStorage | 跨页面数据传递 |
| DOM TreeWalker | 文章内文本高亮 |

## 3. 核心组件

### 3.1 NewPostNotification 组件

**文件路径**: `components/NewPostNotification.tsx`

**功能**:
- 定时检查 RSS 更新（每 5 分钟）
- 检测新文章和文章更新
- 使用 diff 算法计算变更内容
- 悬浮通知面板展示
- 支持查看变更详情
- 红点提示未读新文章

**核心代码**:
```typescript
// 存储键定义
const DB_NAME = 'cofe-blog-rss-store'
const STORE_NAME = 'posts'
const LAST_SEEN_TIME_KEY = 'cofe-last-seen-time'
const CHECK_INTERVAL = 5 * 60 * 1000 // 5分钟

// RSS 数据获取
const fetchRSS = async (): Promise<Post[]> => {
  const response = await fetch('/atom.xml', { cache: 'no-store' })
  const text = await response.text()
  const parser = new DOMParser()
  const xml = parser.parseFromString(text, 'text/xml')
  const entries = Array.from(xml.querySelectorAll('entry'))
  
  return entries.map((entry) => {
    const title = entry.querySelector('title')?.textContent || ''
    const link = entry.querySelector('link')?.getAttribute('href') || ''
    const guid = entry.querySelector('id')?.textContent || link
    const updated = entry.querySelector('updated')?.textContent || ''
    const pubDate = new Date(updated).getTime()
    const content = entry.querySelector('content')?.textContent || ''
    return { title, link, guid, pubDate, content }
  })
}

// 差异计算
const computeDiff = (oldText: string, newText: string) => {
  // 去除 HTML 标签
  const stripHtml = (html: string): string => {
    const tmp = document.createElement('DIV')
    tmp.innerHTML = html
    return tmp.textContent || tmp.innerText || ''
  }
  
  const cleanOld = stripHtml(oldText)
  const cleanNew = stripHtml(newText)
  const diffs = diffLines(cleanOld, cleanNew)
  
  return diffs.map(part => ({
    value: part.value,
    added: part.added,
    removed: part.removed
  }))
}

// 检查新文章（基于上次查看时间）
const checkForNewPosts = async () => {
  const lastSeenTime = Number(localStorage.getItem(LAST_SEEN_TIME_KEY)) || 0
  
  for (const post of fetchedPosts) {
    const existingPost = storedPosts.find((p) => p.guid === post.guid)
    
    if (!existingPost && post.pubDate > lastSeenTime) {
      // 新文章
      newOrUpdatedPosts.push({ ...post, isUpdated: false })
    } else if (existingPost?.content !== post.content && post.pubDate > lastSeenTime) {
      // 更新的文章
      const diff = computeDiff(existingPost.content, post.content)
      if (diff) {
        newOrUpdatedPosts.push({ ...post, isUpdated: true, diff })
      }
    }
  }
}

// 清除通知
const clearNotification = useCallback(() => {
  localStorage.setItem(LAST_SEEN_TIME_KEY, Date.now().toString())
  setNewPosts([])
  setHasNewPosts(false)
}, [])
```

**UI 特性**:
- 铃铛图标带红点提示（`showDot = hasNewPosts && newPosts.length > 0 && isMinimized`）
- 可展开/收起通知面板
- 新文章标记为"新文章"（绿色标签）
- 更新文章标记为"更新"（蓝色标签），可查看 diff
- 支持"文中查看"跳转到文章页面
- 毛玻璃效果背景

### 3.3 PostContentHighlighter 组件

**文件路径**: `components/PostContentHighlighter.tsx`

**功能**:
- 在文章正文内高亮显示变更内容
- 使用 DOM TreeWalker 遍历文本节点
- 查找并高亮变更的文本
- 支持清除高亮
- 显示变更统计

**核心代码**:
```typescript
// 高亮文章中的变更内容
const highlightChanges = useCallback(() => {
  const articleContent = document.querySelector('.markdown-content, .prose')
  if (!articleContent) return

  changes.diff.forEach((part) => {
    if (part.added) {
      highlightText(articleContent, part.value, 'added')
    } else if (part.removed) {
      highlightText(articleContent, part.value, 'removed')
    }
  })
}, [changes, highlighted])

// 在文本中高亮指定内容
const highlightText = (container: Element, text: string, type: 'added' | 'removed') => {
  const walker = document.createTreeWalker(container, NodeFilter.SHOW_TEXT, null)
  const textNodes: Text[] = []
  let node: Node | null

  // 收集所有文本节点
  while ((node = walker.nextNode())) {
    textNodes.push(node as Text)
  }

  // 处理每个文本节点
  textNodes.forEach((textNode) => {
    const content = textNode.textContent || ''
    if (content.includes(text.trim())) {
      const span = document.createElement('span')
      span.className = type === 'added' 
        ? 'diff-highlight-added bg-green-200 dark:bg-green-900/50 text-green-900 dark:text-green-100 px-1 rounded'
        : 'diff-highlight-removed bg-red-200 dark:bg-red-900/50 text-red-900 dark:text-red-100 px-1 rounded line-through opacity-70'
      span.textContent = text.trim()
      
      // 替换文本节点为高亮 span
      const parts = content.split(text.trim())
      const fragment = document.createDocumentFragment()
      parts.forEach((part, index) => {
        if (part) fragment.appendChild(document.createTextNode(part))
        if (index < parts.length - 1) fragment.appendChild(span.cloneNode(true))
      })
      textNode.parentNode?.replaceChild(fragment, textNode)
    }
  })
}

// 清除高亮
const clearHighlight = useCallback(() => {
  const highlights = document.querySelectorAll('.diff-highlight-added, .diff-highlight-removed')
  highlights.forEach((el) => {
    const parent = el.parentNode
    if (parent) {
      parent.replaceChild(document.createTextNode(el.textContent || ''), el)
      parent.normalize() // 合并相邻文本节点
    }
  })
  setHighlighted(false)
  sessionStorage.removeItem('active-post-changes')
}, [])
```

**UI 特性**:
- 位置：固定右下角 (`bottom-24 right-4`)
- 初始状态：显示"高亮变更"按钮
- 点击后：高亮文章内变更，显示统计信息
- 统计：新增数量（绿色）、删除数量（红色）
- 清除按钮：恢复原状

## 4. IndexedDB 存储

### 4.1 数据库结构
```typescript
const DB_NAME = 'cofe-blog-rss-store'
const DB_VERSION = 1
const STORE_NAME = 'posts'

interface StoredPost {
  id: string          // 作用域 + GUID，如 "cofe.381359.xyz:post-guid"
  title: string
  link: string
  guid: string
  pubDate: number     // 发布时间戳
  content: string     // 文章内容（用于对比）
  isUpdated?: boolean // 是否更新
  diff?: DiffPart[]   // 变更内容
}

interface DiffPart {
  value: string
  added?: boolean
  removed?: boolean
}
```

### 4.2 存储操作
```typescript
// 打开数据库
const openDB = (): Promise<IDBDatabase> => {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open(DB_NAME, DB_VERSION)
    request.onerror = () => reject(request.error)
    request.onsuccess = () => resolve(request.result)
    request.onupgradeneeded = (event: IDBVersionChangeEvent) => {
      const db = (event.target as IDBOpenDBRequest).result
      if (!db.objectStoreNames.contains(STORE_NAME)) {
        db.createObjectStore(STORE_NAME, { keyPath: 'id' })
      }
    }
  })
}

// 生成作用域 ID（支持多域名）
const generateId = (guid: string): string => {
  const scope = window.location.hostname
  return `${scope}:${guid}`
}

// 获取存储的文章
const getStoredPosts = async (db: IDBDatabase): Promise<StoredPost[]> => {
  return new Promise((resolve, reject) => {
    const transaction = db.transaction([STORE_NAME], 'readonly')
    const store = transaction.objectStore(STORE_NAME)
    const request = store.getAll()
    request.onsuccess = () => resolve(request.result as StoredPost[])
    request.onerror = () => reject(request.error)
  })
}

// 保存文章
const savePosts = async (db: IDBDatabase, posts: Post[]): Promise<void> => {
  return new Promise((resolve, reject) => {
    const transaction = db.transaction([STORE_NAME], 'readwrite')
    const store = transaction.objectStore(STORE_NAME)
    posts.forEach((post) => {
      const itemToSave: StoredPost = { ...post, id: generateId(post.guid) }
      store.put(itemToSave)
    })
    transaction.oncomplete = () => resolve()
    transaction.onerror = () => reject(transaction.error)
  })
}
```

## 5. 红点提示机制

### 5.1 问题
之前的问题是：用户清空通知后，下次刷新页面，之前的新文章仍然会被标记为"新"的，导致红点一直显示。

### 5.2 解决方案
使用 `LAST_SEEN_TIME_KEY` 记录用户上次查看通知的时间：

```typescript
// 存储键
const LAST_SEEN_TIME_KEY = 'cofe-last-seen-time'

// 检查新文章时，只显示发布时间在上次查看之后的文章
const lastSeenTime = Number(localStorage.getItem(LAST_SEEN_TIME_KEY)) || 0

if (!existingPost && post.pubDate > lastSeenTime) {
  newOrUpdatedPosts.push({ ...post, isUpdated: false })
}

// 清空通知时更新时间
const clearNotification = useCallback(() => {
  localStorage.setItem(LAST_SEEN_TIME_KEY, Date.now().toString())
  setNewPosts([])
  setHasNewPosts(false)
}, [])
```

### 5.3 工作流程
1. **首次访问** - `lastSeenTime` 为 0，显示所有文章
2. **用户查看通知** - 看到新文章列表
3. **用户点击"清空"** - 记录当前时间为 `lastSeenTime`
4. **下次检查** - 只显示 `pubDate > lastSeenTime` 的文章
5. **有新文章发布** - `pubDate > lastSeenTime`，显示红点

## 6. 主题闪烁问题解决

### 6.1 问题描述
深色模式下刷新页面，表格等组件会先以亮色模式显示，然后切换到深色模式，造成闪烁（FOUC - Flash of Unstyled Content）。

### 6.2 解决方案
在 HTML 的 `<head>` 中添加内联脚本，在页面渲染前就设置主题：

```html
<!-- app/layout.tsx -->
<Head>
  <script
    dangerouslySetInnerHTML={{
      __html: `
        (function() {
          function getTheme() {
            const savedTheme = localStorage.getItem('cofe-blog-theme');
            if (savedTheme === 'dark' || savedTheme === 'light') {
              return savedTheme;
            }
            return window.matchMedia('(prefers-color-scheme: dark)').matches 
              ? 'dark' : 'light';
          }
          const theme = getTheme();
          document.documentElement.classList.add(theme);
        })();
      `,
    }}
  />
</Head>
```

### 6.3 工作原理
1. **服务器端渲染** - HTML 中没有主题类
2. **浏览器解析** - 内联脚本立即执行，设置主题
3. **页面渲染** - 已经有正确的主题类
4. **React hydration** - ThemeProvider 接管，避免重复设置

### 6.4 ThemeProvider 优化
```typescript
useEffect(() => {
  // 获取当前已设置的主题（由内联脚本设置）
  const currentClass = document.documentElement.classList.contains('dark') 
    ? 'dark' : 'light'
  
  // 只有当主题变化时才更新
  if (currentClass !== theme) {
    document.documentElement.classList.remove('light', 'dark')
    document.documentElement.classList.add(theme)
  }

  // 保存到 localStorage
  localStorage.setItem(STORAGE_KEY, theme)
}, [theme])
```

## 9. 注意事项

1. **首次访问** - 自动检测并展开通知面板
2. **定时检查** - 每 5 分钟自动检查一次
3. **数据持久化** - 使用 IndexedDB，清理浏览器数据会丢失历史
4. **跨域名** - 使用 `window.location.hostname` 作为作用域前缀
5. **兼容性** - 需要浏览器支持 IndexedDB 和 CSS backdrop-filter
6. **隐私模式** - 部分浏览器隐私模式下 IndexedDB 不可用
7. **文章内高亮** - 依赖 `.markdown-content` 或 `.prose` 类名
