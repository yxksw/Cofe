# 新文章通知功能技术文档

## 1. 功能概述

新文章通知功能是一个基于 RSS 订阅的博客文章更新检测系统，主要功能包括：

- **自动检测**：页面加载后自动获取 RSS 订阅源
- **IndexedDB 存储**：使用浏览器本地 IndexedDB 存储已读取的文章内容
- **差异比较**：比较新旧文章内容，检测更新
- **通知弹窗**：显示新文章和更新文章列表
- **文章内高亮**：在文章页面显示变更内容的差异高亮
- **一键跳转**：点击通知项自动跳转到文章并高亮变更

### 3.2 数据类型定义

```typescript
interface Post {
  title: string;           // 文章标题
  link: string;            // 文章链接
  guid: string;           // 文章唯一标识
```

### 3.4 差异计算

```typescript
function computeDiff(oldText: string, newText: string) {
  // 规范化 HTML：移除多余空白，解析为行
  const cleanOld = normalizeForDiffHtml(oldText)
  const cleanNew = normalizeForDiffHtml(newText)

  // 使用 diff 库计算行级差异
  const diffs = Diff.diffLines(cleanOld, cleanNew)
  const hasChanges = diffs.some((part) => part.added || part.removed)

  return hasChanges ? diffs : null
}
```

### 3.5 IndexedDB 操作

```typescript
// 打开数据库
const openDB = (): Promise<IDBDatabase> => {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open(DB_NAME, DB_VERSION)
    request.onerror = () => reject(request.error)
    request.onsuccess = () => resolve(request.result)
    request.onupgradeneeded = (event) => {
      const db = event.target.result
      // 创建对象存储
      if (!db.objectStoreNames.contains(STORE_OLD)) {
        db.createObjectStore(STORE_OLD, { keyPath: 'id' })
      }
      if (!db.objectStoreNames.contains(STORE_NEW)) {
        db.createObjectStore(STORE_NEW, { keyPath: 'id' })
      }
    }
  })
}

// 保存文章
const savePosts = async (db: IDBDatabase, posts: Post[]) => {
  const transaction = db.transaction([STORE_OLD], 'readwrite')
  const store = transaction.objectStore(STORE_OLD)

  posts.forEach((post) => {
    store.put({ ...post, id: generateId(post.guid) })
  })
}
```

## 4. 组件说明

### 4.1 NewPostNotification 组件

主要职责：

1. **初始化检测**：组件挂载时立即检查新文章
2. **定时轮询**：每 5 分钟自动检查一次
3. **通知展示**：显示新文章/更新文章列表
4. **状态管理**：控制弹窗展开/收起

核心逻辑：

```typescript
useEffect(() => {
  checkForNewPosts()
  // 定时检查
  intervalRef.current = setInterval(checkForNewPosts, CHECK_INTERVAL)

  return () => clearInterval(intervalRef.current)
}, [checkForNewPosts])
```

### 4.2 PostContentHighlighter 组件

主要职责：

1. **检测 URL 参数**：检查 `?diff=1` 参数
2. **读取差异数据**：从 sessionStorage 获取变更信息
3. **应用高亮**：在文章内容中高亮显示变更
4. **清除状态**：关闭高亮时清理所有状态

核心逻辑：

```typescript
const highlightChanges = useCallback(() => {
  const container = document.querySelector('.markdown-content')
  if (container && changes?.diff) {
    applyInlineDiff(container, changes.diff)
  }
}, [changes])

const clearHighlight = useCallback(() => {
  const container = document.querySelector('.markdown-content')
  if (container) {
    clearInlineDiff(container)
  }
  sessionStorage.removeItem(DEBUG_STATE_KEY)
}, [])
```

### 4.3 PostDiffInArticle 组件

主要职责：

1. **差异面板**：在文章侧边显示变更概览
2. **统计信息**：显示新增/删除行数
3. **关闭功能**：一键关闭差异显示

### 4.4 post-inline-diff 工具库

核心函数：

| 函数 | 说明 |
|------|------|
| `applyInlineDiff` | 在文章中应用差异高亮 |
| `clearInlineDiff` | 清除所有差异标记 |
| `findBlockByText` | 根据文本查找对应 DOM 元素 |
| `findImgBySrc` | 根据 src 查找图片元素 |

## 5. 差异高亮原理

### 5.1 差异定位

```
文章内容 DOM
    │
    ▼
┌─────────────────────────────────────┐
│  遍历差异块 (Hunk)                   │
│  查找上下文元素作为锚点               │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  对于每个变更行：                    │
│  - 新增：标记目标元素 + 插入高亮节点  │
│  - 删除：标记目标元素 + 插入删除线    │
└─────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────┐
│  生成 HTML 结构：                    │
│  <div class="post-inline-diff-add-line">新增内容</div>
│  <del class="post-inline-diff-del-line">删除内容</del>
└─────────────────────────────────────┘
```

## 6. 工作流程

### 6.1 首次访问

```
用户访问博客
    │
    ▼
NewPostNotification 组件挂载
    │
    ▼
获取 RSS 数据 (/atom.xml)
    │
    ▼
存储到 IndexedDB (STORE_OLD)
    │
    ▼
设置初始时间戳到 localStorage
    │
    ▼
不显示通知（首次访问）
```

### 6.2 后续访问

```
用户访问博客
    │
    ▼
获取 RSS 数据
    │
    ▼
读取 IndexedDB 中存储的文章
    │
    ▼
逐篇比较内容差异
    │
    ├─ 新文章 ──→ 标记为 "新文章"
    │
    └─ 内容变化 ─→ 计算 diff → 标记为 "更新"
    │
    ▼
更新 IndexedDB 存储
    │
    ▼
显示通知弹窗 + 红点提示
```

### 6.3 查看变更

```
用户点击通知项
    │
    ▼
跳转到文章页 (?diff=1#post-diff)
    │
    ▼
PostContentHighlighter 读取 sessionStorage
    │
    ▼
应用差异高亮到文章内容
    │
    ▼
自动滚动到第一个变更位置
```

### 6.4 关闭通知

```
用户点击关闭按钮
    │
    ▼
清除 sessionStorage 中的差异状态
    │
    ▼
清除 localStorage 中的通知状态
    │
    ▼
移除 URL 参数 (?diff=1)
    │
    ▼
清除文章中的所有高亮标记
```

## 9. 注意事项

1. **隐私考量**：所有数据存储在用户本地浏览器，不涉及服务器端存储
2. **性能考虑**：差异计算和 DOM 操作可能影响性能，建议对大文章进行优化
3. **缓存策略**：RSS 请求使用 `cache: 'no-store'` 确保获取最新数据
4. **清理机制**：关闭通知后会自动清理相关状态，避免持久化污染
